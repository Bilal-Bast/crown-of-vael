# Phase 11 development trust boundary

The Phase 11 providers and social services are local development foundations. They are not secure, authoritative, or resistant to save editing. The development cloud provider writes user data files to a separate local cloud-style directory; it is not a remote backup service.

A production backend must validate player identity, cloud-save ownership and versions, purchases and economy transactions, PvP snapshots and results, friend requests, guild membership and permissions, Guild Boss progress, and every chat message. Chat filtering in this client is a usability placeholder. It does not provide moderation or safety enforcement.

Core PvE and local saves remain available when any online provider fails. Do not treat client-side rating, guild, or entitlement state as proof of a server-authorized result.
